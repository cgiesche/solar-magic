Solar Magic

A Super Mario World level editor for the browser.

Edit levels, the overworld, graphics, music and the title screen, test them in the built-in emulator, and install patches, blocks, sprites and music from SMW Central.

A new project starts from a clean Super Mario World (US) ROM. You can also drop the ROM or a project file onto this page.

Workspace G 1

Level

Levels are drawn by running the game's own code in an emulator, so the editor shows them as the game does, animated tiles and palettes included.

  • Objects, sprites and exits

    Place and resize objects on layer 1 and layer 2, place sprites, and set up entrances, exits and screen exits. Horizontal and vertical levels, backgrounds and layer 3.

  • Message boxes

    Each level's two messages are typed into the game's 18×8 box, beside the level. The editor finds out by emulation which message a message box opens.

  • Search and commands

    Ctrl+K finds levels, objects, sprites, Map16 tiles and commands. Tiles are also found by what they do: solid, deadly, gives a coin.

Prefabs

A prefab is a group of Map16 tiles stored under its own number and placed like an object. A change to a prefab applies to every place it is used, in all levels. Lunar Magic's Custom Collections insert copies; prefabs stay linked.

  • Saved from selected objects, up to 64×64 tiles, with transparent cells
  • Less level data than the same tiles as Direct Map16 objects; the dialog shows from which placement on it saves space
  • Repeated Direct Map16 arrangements across the levels are suggested as prefabs
  • A placed prefab can be broken up into the objects it was made from
  • Uses only extended object 04, free in the game and in Lunar Magic; no game code is changed

Test play

T starts the open level in the built-in emulator, with sound. Keyboard and gamepad are supported.

  • Shift+T starts with Mario at the mouse position
  • Hold Backspace to rewind
  • CPU load, lag frames and sprite slots per frame
  • Death markers: where Mario died and what killed him
  • Save states
  • From the overworld: a new game at the events shown on the map

Level checks

The editor checks the open level while you work and lists what it finds under Problems. Show takes you to the place in the level. Some checks play the level through in the background.

  • Pipes and doors without an exit, exits without a pipe or door, exits to secondary entrances that are not set up
  • Slowdown per screen
  • Sprites that fall out of the level right after appearing or are stuck between blocks
  • Sprites the game leaves out or draws incompletely because of the sprite memory setting, with a fix
  • More than 128 sprites; objects, sprites or exits beyond the last screen

Block behavior from the game itself

What a block does is found out by running the game in an emulator: Mario hits it from below, lands on it, walks against it and tries to enter it. There are no lists of known tile numbers, so the game's blocks, patched blocks and custom GPS blocks are handled the same way.

  • What a block gives when hit, drawn over the block in the level
  • Collision overlay: solid, passable, slopes, sides that hurt or kill
  • Blocks that change with a P-switch or the ON/OFF switch
  • Pipes and doors that can be entered, with their direction
  • What a sprite gives when hit or jumped on
  • Jump arcs (J) from Mario's measured speeds

Workspace G 2

Overworld

The main map and the six submaps, shown as they are after any set of events. The editor follows the paths the way Mario walks them and tells you where he can't get.

  • Paths drawn as a route

    Drag a route from one level to the next and the editor puts the path tiles. Level tiles, stars and pipes are objects on the map; a level moved takes its paths along.

  • Events

    Check events in the list to see the map after them. A level's properties say what beating it does, one sentence per exit, and arrows on the map show which levels each exit opens.

  • World check

    Levels Mario never reaches, dead ends, links that leave him stuck, events no exit runs. The ROM's limits are shown as gauges beside the actions they stop.

  • Names, music and sprites

    Level names as free text, a song per submap, the overworld's sprites, and custom overworld sprites with BOWSIE.

  • Terrain and graphics

    Layer 2 is painted in 8×8 tiles or in pieces already on the map. Each submap has its own graphics files, palettes and ExAnimation.

  • Import

    Take over the whole overworld of another ROM, as Lunar Magic's overworld copy does.

Workspace G 3

Graphics

Palettes, 8×8 graphics, Map16 tiles and animations for the open level or a submap, with a preview of where they are used.

  • Map16 tiles

    Foreground, background and overworld tiles: their four 8×8 quarters, what they act like, and the levels they are used in. Unused tiles can be marked.

  • Graphics and palettes

    A pixel editor for 8×8 tiles, ExGFX files per level and per submap, and palettes that show where each color comes from.

  • Animations

    ExAnimation for levels and for the overworld, with triggers. The level view and the pickers play them.

  • Import and export

    PNG images and Lunar Magic's Map16, ExGFX and palette files.

Workspace G 4

Game

Everything between switching the console on and the first step on the overworld. Each screen is shown with its picture taken from the emulated game.

  • Title screen

    Paint the logo, the frame and the copyright line. Record Mario's movement on the title screen with the keyboard or a gamepad, right on the page.

  • Movement that stays in sync

    If a later change to the title screen level sends Mario another way than recorded, the editor tells you at which frame.

  • Menus and prompts

    The texts of file select, file erase, player select, the save prompt and the game over prompt, and the Nintendo Presents logo.

  • Start of game

    The intro level, the lives and the start position of a new save file, in one place.

  • Play from power-on

    See the whole sequence as a player does, on empty save files or on a save at the events you choose.

  • Overworld border

    Each map's border, edited as the screen the game shows.

Community content

Patches, blocks, sprites and music from the community

Solar Magic uses the formats of the established SMW tools. Drop a download from SMW Central onto the Packages workspace (G 5): it is installed unchanged as one package, and can be removed again as one.

There is no list.txt to write and no tool to run. The editor reads what a download contains, gives its blocks, sprites and songs their numbers, and shows where everything goes before it installs.

FAQ

Questions

What is Solar Magic?
Solar Magic is a free level editor for Super Mario World. It runs in your web browser and lets you build your own levels and ROM hacks without installing anything.
Do I need to install anything?
No. Solar Magic runs in any modern web browser. A desktop app is available as well.
Where do I get a ROM?
Solar Magic does not come with the game. You start from a clean Super Mario World (US) ROM that you made from your own copy.
Can I use patches, blocks and sprites from SMW Central?
Yes. Drop the download onto the Packages workspace; patches, UberASM code, blocks, sprites, music and graphics in it are installed together. You don't write a list.txt or run GPS, PIXI, UberASM Tool or AddmusicK yourself.
Is my ROM uploaded anywhere?
No. Your ROM and your work stay on your own computer. Nothing is sent to a server.
How does it compare to Lunar Magic?
Solar Magic aims to cover Lunar Magic's features and uses its file formats. It adds test play inside the editor, checks of levels and the overworld, and installs community resources without separate tools.
