Solar Magic

A Super Mario World level editor for the browser.

Edit levels, the overworld, graphics and music, test them in the built-in emulator, and install patches, blocks, sprites and music from SMW Central.

A new project starts from a clean Super Mario World (US) ROM. You can also drop the ROM or a project file onto this page.

  • Free
  • Nothing to install
  • Files stay on your computer
  • Desktop app for Windows, macOS & Linux

Features

What the editor does

Levels are drawn by running the game's own code in an emulator, so the editor shows them as the game does.

Levels and the overworld

Place objects and sprites, set up entrances, exits and screen exits, and edit backgrounds. On the overworld: the map, level tiles, paths, events and the directions each exit opens.

  • Objects, sprites, entrances and exits, layer 2 and layer 3
  • Overworld paths, events and level tile settings
  • Undo and redo; search across objects, tiles and sprites

Prefabs

A prefab is a group of Map16 tiles stored under its own number and placed like an object. A change to a prefab applies to every place it is used, in all levels. Lunar Magic's Custom Collections insert copies; prefabs stay linked.

  • Saved from selected objects, up to 64×64 tiles, with transparent cells
  • Less level data than the same tiles as Direct Map16 objects; the dialog shows from which placement on it saves space
  • Repeated Direct Map16 arrangements across the levels are suggested as prefabs
  • A placed prefab can be broken up into the objects it was made from
  • Uses only extended object 04, free in the game and in Lunar Magic; no game code is changed

Test play

T starts the current level in the built-in emulator, with sound. Keyboard and gamepad are supported.

  • Shift+T starts with Mario at the mouse position
  • CPU load, lag frames and sprite slots per frame
  • Death markers: where Mario died and what killed him
  • Save states

Level checks

The editor checks the open level while you work and lists what it finds in the status bar. Clicking an entry shows the place in the level. Some checks play the level through in the background.

  • Pipes and doors without an exit, exits without a pipe or door, exits to secondary entrances that are not set up
  • Slowdown per screen
  • Sprites that fall out of the level right after appearing or are stuck between blocks
  • Sprites drawn incompletely because of the sprite memory setting, with a fix
  • More than 128 sprites; objects, sprites or exits beyond the last screen

Block behavior from the game itself

What a block does is found out by running the game in an emulator: Mario hits it from below, lands on it, walks against it and tries to enter it. There are no lists of known tile numbers, so the game's blocks, patched blocks and custom GPS blocks are handled the same way.

  • What a block gives when hit, drawn over the block in the level
  • Collision overlay: solid, passable, slopes, deadly
  • Pipes and doors that can be entered, with their direction
  • What a sprite gives when hit or jumped on
  • Jump arcs (J) from Mario's measured speeds

Graphics, colors and animation

Pixel editor for 8×8 tiles, Map16 editor, palettes and animations, with a preview of the current level.

  • Map16 tiles with what they act like and where they are used
  • ExGFX, palettes and ExAnimation
  • Import PNG images and Lunar Magic graphics files

  • Music

    AddmusicK songs and sound effects; playback of each level's music in the editor.

  • Message boxes

    Edit the message box texts, with a preview in the game's font.

  • Export

    A playable ROM or a BPS patch against the clean game.

Community content

Compatible with existing resources

Solar Magic uses the formats of the established SMW tools. A download from SMW Central is installed unchanged as one package, and can be removed again as one.

  • Asarpatches
  • UberASM Toollevel, game mode and global code
  • GPScustom blocks, their behavior found by emulation
  • PIXIcustom sprites
  • AddmusicKsongs and sound effects
  • Callistoprojects such as the Romhack Races baserom
  • Lunar Magic formatsMap16, ExGFX, palettes, level files (.mwl)
  • BPSpatch export

FAQ

Questions

What is Solar Magic?
Solar Magic is a free level editor for Super Mario World. It runs in your web browser and lets you build your own levels and ROM hacks without installing anything.
Do I need to install anything?
No. Solar Magic runs in any modern web browser. A desktop app is available as well.
Where do I get a ROM?
Solar Magic does not come with the game. You start from a clean Super Mario World (US) ROM that you made from your own copy.
Can I use patches, blocks and sprites from SMW Central?
Yes. Drop the download into the Packages dialog; patches, UberASM code, blocks, sprites, music and graphics in it are installed together.
Is my ROM uploaded anywhere?
No. Your ROM and your work stay on your own computer. Nothing is sent to a server.
How does it compare to Lunar Magic?
Solar Magic aims to cover Lunar Magic's features and uses its file formats. It adds test play inside the editor and installs community resources without separate tools.
